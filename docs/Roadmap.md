# Roadmap

## MVP

- Hourly and manually triggered AWS announcement collection.
- Historical JSON dataset with hash-based deduplication.
- Searchable, filterable dark dashboard.
- GitHub Actions CI, schema validation, and GitHub Pages deployment.

## Phase 2

- Push notifications for selected categories or sources.
- Per-service subscriptions and user preferences.
- AWS Health event monitoring, subject to AWS access and API requirements.
- Optional Bedrock-based summarization, with explicit cost and credential controls.
- Source freshness and collector health reporting.
